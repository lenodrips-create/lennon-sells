About me

@lenodrips

I'm Lennon. I build what I imagine.

I'm a developer who likes building the whole thing: the engine, the interface and the page that tells people about it.

Most of my work starts as a question. Could I make my own web browser? That became Kepler, written in C++ on Qt and Chromium. Could a full code studio run inside a browser tab? That became CTerm Studio, with a C core compiled to WebAssembly.

I care about how software feels as much as what it does: fast, private, and a little bit cinematic.
