process

How I ship.

01

Sketch it

Figure out how it should feel before writing a line. Then pick the stack that fits, not the one that's trending.

02

Build it

Get the core working first: a browser that loads pages, a shell that runs commands, a cart that adds up.

03

Polish it

Animations, keyboard support, small screens, reduced motion. The details are what make people stay.

04

Ship it

CI builds, release pages and GitHub Pages deploys. If it isn't shipped, it doesn't count.
